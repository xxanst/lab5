# Первый пост

Учебный проект: одностраничный сайт (лендинг) онлайн-курса по SMM для начинающих.

## О проекте

- **Тематика:** курс по SMM для студентов и начинающих специалистов
- **Цель сайта:** рассказать о курсе, показать программу и тарифы, собрать заявки
- **Технологии:** HTML, CSS, JavaScript
- **Создан с помощью ИИ:** код сгенерирован LLM и доработан ИИ-агентом


## Ветки

- `main` — основная версия сайта
- `add-photos` — добавление фотографий
- `scroll-animation` — анимация появления блоков


## Запуск

Откройте `index.html` в браузере или запустите через расширение Live Server в VS Code.
